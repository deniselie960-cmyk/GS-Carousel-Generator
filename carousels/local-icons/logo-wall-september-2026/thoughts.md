# Local Icons Logo Wall — Development Notes

## Goal

Create one 4:5 Instagram post that presents the participating Local Icons brands, with VIP Buyer Brands more prominent than Non-VIP brands.

## Approved structure

1. Approved Local Icons horizontal lockup.
2. `Where Local Becomes Iconic.`
3. VIP Buyer Brand section in this exact order:
   - Advance Digitals
   - BARDI
   - UNITECH
   - HIA
   - Eigerindo
   - Youware
   - Lumea
   - Mediatech
4. `LOCAL EXHIBITOR` section with no required ordering, set in two rows of five and visually smaller than VIP.
5. Event details:
   - 17–19 September 2026
   - Hall B
   - JICC Senayan, Jakarta

## Design decisions

- Working canvas: 1080 × 1350px; export at 2160 × 2700px.
- Use individual white pill-like cards with identical dimensions within each tier.
- VIP uses four columns and larger cards; Local Exhibitor uses five columns and smaller cards.
- Center the campaign lockup, headline, tier labels, and event block on one optical axis.
- Use centered tier labels with short rules on both sides.
- Enlarge the campaign headline, date pill, hall, and venue so the event information reads as primary content.
- Preserve each logo's natural proportions using contained images and optical zoom adjustments.
- Use Local Icons teal, purple, blue, and yellow as cropped edge forms on a quiet warm-neutral field.
- Use the dark event-date pill from the Local Icons key visual.
- Add a large circular `52+ Brands` medallion overlapping the upper-left edge of the logo wall. Use one flat Local Icons blue fill, no outline or internal rings, and non-italic sans-serif lettering.
- Set the campaign line as `Where Local Becomes Iconic` without a final period.
